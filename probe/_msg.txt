Pick a picture on the phone and send it with the prompt

DSH takes image bytes inline on session/prompt and promotes them to a durable
attachment, so the phone only has to stage the picked file and hand it over in
the same message as the text. The composer keeps staged pictures visible and
removable until send, and refuses extensions the Host would reject rather than
letting a whole prompt fail after the message was typed.

Reading a picture back is a second request: events carry an attachment id, not
bytes, so each thumbnail is fetched once through session/attachment and cached
by id.
